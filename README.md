# Customer Churn Analysis

## Project Overview
This project focuses on analyzing customer churn to understand customer behavior and identify factors that may contribute to customers leaving a company.

## Project Summary
In this project, customer data was analyzed to explore customer churn patterns and understand the relationship between customer characteristics and churn.

The analysis includes data exploration, visualization, and insights derived from the customer dataset.

## Files Included
- `Customer Churn.csv` – Customer dataset
- `TCA.ipynb` – Jupyter Notebook containing the analysis
- `TCA-Summary.pdf` – Detailed project report

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
